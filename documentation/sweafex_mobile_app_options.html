Engineering Breakdown & Scope Effort

What Work Is Involved in Each Option?

Understanding the development effort, platform dependencies, and architectural logic that drive the timeline and cost differences.
Engineering Scope
Effort Analysis
PWA Engineering 2 Wks · ₹50k
  • Workflow review: Audit completed web app to identify mobile-essential driver & staff flows.
  • Mobile UI refinement: Optimize responsive layouts, touch targets, forms, and mobile menus.
  • PWA manifest & service worker: Configure home-screen install banners, icons, and asset caching.
  • Core testing: Verify authentication, role limits, trip updates, and mobile browser camera uploads.
  • Deployment & handover: Direct production push with zero app-store delays.
Key Focus: Refines and adapts existing web frontend without developing a secondary codebase.
Android App Engineering 4 Wks · ₹1,00,000
  • Dedicated mobile screens: Design & build mobile-native UI components and tab-based navigation.
  • REST API integration: Connect mobile application securely to existing backend data endpoints.
  • Operational workflows: Implement role-based login, live trip tracking cards, and direct camera POD upload.
  • Hardware & network handling: Manage device permissions, connectivity interruptions, and loading states.
  • Device testing & release build: Test on representative Android screen sizes and compile production APK/AAB.
Key Focus: Builds a standalone mobile client while consuming backend business logic and databases.
Dual App Engineering 6 Wks · ₹2,00,000
  • Cross-platform architecture: Plan unified codebase delivering native ergonomics on both operating systems.
  • Dual UI implementation: Adapt layouts for Material (Android) and Cupertino (iOS) navigation conventions.
  • Shared backend integration: Secure endpoint consumption across both mobile ecosystems.
  • Dual-ecosystem QA: Extensive verification across various Android hardware and Apple iOS devices.
  • Store release preparation: Package production binaries and assist with Google Play & Apple App Store submission.
Key Focus: Full two-ecosystem support, device matrix testing, and compliance with dual store guidelines.
Pricing Logic
PWA (₹50,000): Low cost because it refines and reuses the existing web frontend codebase directly.
Android (₹1,00,000): Moderate cost because it requires constructing a separate mobile UI and native device layer.
Android + iOS (₹2,00,000): Higher cost due to dual operating system validation, Apple compliance, and dual store overhead.

Governance & Scope Boundaries

Assumptions, Dependencies & Exclusions

A clear framework of technical prerequisites, third-party items, and commercial boundaries governing all mobile options.
Architecture
Technical Governance
Core Engineering Assumptions
  • Web software complete: The primary SweafEx web application is 100% developed, tested, and operational before mobile development initiates.
  • Backend & API readiness: Required database models, API endpoints, authentication mechanisms, and user roles already exist and are reusable.
  • Codebase structure: Existing business logic and backend services are sufficiently structured to support external mobile queries without rewrite.
  • Agreed mobile scope: Development is strictly focused on the agreed mobile operational workflows (trip viewing, milestone reporting, POD upload).
Excluded Unless Agreed Separately
  • New backend features: Creation of unbuilt server workflows, complex ERP modules, or major changes to core business logic.
  • Core software redesigns: Major structural overhauls or visual redesigns of the foundational web application.
  • Hosting & third-party APIs: Cloud server hosting, WhatsApp Business API credits, Google Maps API usage, or SMS gateway fees.
  • App store fees & maintenance: Google Play Developer ($25 one-time) and Apple Developer Program ($99/year) accounts, and ongoing app maintenance.
Architectural Review Notice
These timelines and prices assume high backend reusability. The definitive scope, final cost, and delivery schedule can only be confirmed after the web software is complete and Octagram has conducted a formal architectural code review. Should additional server endpoints or refactoring be required, revised estimates will be agreed upon with SweafEx before work commences.
